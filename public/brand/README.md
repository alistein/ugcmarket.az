# UGCMarket brand kit

Logo: viewfinder mark + record-dot wordmark (`ugcmarket.az`, Geist SemiBold, outlined in the SVGs so no font is needed).
In the app use the `Logo` component (`src/components/shared/logo.tsx`), not these files.

## Files

| File | Use |
|---|---|
| `ugcmarket-logo.svg` / `.png` | Full logo on light backgrounds |
| `ugcmarket-logo-dark.svg` / `.png` | Full logo on dark backgrounds |
| `ugcmarket-logo-white.svg` / `.png` | Full logo on coral or photos |
| `ugcmarket-logo-black.svg` | One-color print, stamps, engraving |
| `ugcmarket-mark*.svg` | Mark only (same four color versions) |
| `ugcmarket-wordmark*.svg` | Wordmark only (same four color versions) |
| `instagram-profile-1080.png` | Instagram / TikTok profile picture (safe inside the circle crop) |
| `instagram-profile-light-1080.png` | Light alternative for the profile picture |
| `app-icon-1024.png` | App icon, square (the platform rounds the corners) |
| `banner-1500x500.png`, `banner-coral-1500x500.png`, `banner-dark-1500x500.png` | Wide social banner / cover |
| `link-preview-1200x630.png` | Link preview (Open Graph) image |

PNG logos have a transparent background and are 1600 px wide.

## Colors

| Name | Hex | Use |
|---|---|---|
| Coral | `#da3b21` | Record dot, coral backgrounds (light mode `--primary`) |
| Coral, dark mode | `#f96d45` | Record dot on dark backgrounds |
| Ink | `#1f1a17` | Brackets and wordmark on light backgrounds |
| Cream | `#f5f0ea` | Brackets and wordmark on dark backgrounds |
| Paper | `#fcfaf7` | Light background |
| Night | `#1c1917` | Dark background |

## Rules

- Keep clear space around the logo of at least the width of the record dot in the mark on every side.
- Minimum size: mark 16 px, full logo 96 px wide.
- The dot is the only coral element. Do not color the letters.
- Do not stretch, rotate, outline or add shadows.
- On coral use the all-white version. On photos use white or black, whichever has more contrast.
